# 🤖 Invite EdgeForce Bot to Your Server

## Method 1: Direct Invite Link (Easiest)

**Click this link:**

https://discord.com/api/oauth2/authorize?client_id=1473064474511413268&permissions=534723950656&scope=bot%20applications.commands

This will:
1. Open Discord
2. Ask you to select a server
3. Show the permissions the bot needs
4. Click "Authorize"
5. Done!

---

## Method 2: Generate Link Manually

If the link above doesn't work:

1. Go to: https://discord.com/developers/applications/1473064474511413268/oauth2/url-generator

2. Under **SCOPES**, check:
   - ✅ `bot`
   - ✅ `applications.commands`

3. Under **BOT PERMISSIONS**, check:
   - ✅ Send Messages
   - ✅ Send Messages in Threads
   - ✅ Embed Links
   - ✅ Attach Files
   - ✅ Read Message History
   - ✅ Use Slash Commands
   - ✅ Add Reactions

4. Copy the **Generated URL** at the bottom
5. Open that URL in your browser
6. Select your server
7. Click "Authorize"
